# calm-hall-overview

```
bash C:/Users/devboese/.claude/skills/calm-hall-overview/calm_hall_overview.sh
```

It shows the hall as far as `haven:/Hall/hall_overview_visibility.txt` lets it:

- `open`: the room's files, and the rooms inside it.
- `not all at once`: only how many files the room holds.
- `not yet` and `not mine`: only the room and its word.
