# Last updated in the hallmark skill

Wally's idea: hallmark tools stay free of version numbers.

- The hallmark skill's list of tools gets a "last updated" for each tool, in the frame's ISO format, to the minute, like `2026-10-24T19:48+02:00`.
- A raven compares it with the timestamps in its own window, and knows whether it has the newest version.
- The tool builder updates the line with every change to a tool.
