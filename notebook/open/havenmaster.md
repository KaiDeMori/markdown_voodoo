# havenmaster

An always-running calm-comms process that Wally starts and manages by hand.
Like a harbour master, it knows the berths, clears the moorings of boats long gone, and never carries the cargo.

- It adds, and never carries: without it, the hall works as today, and the mail files stay the truth.
- A raven only wakes when a process of its own ends, so every raven keeps a tiny adapter of its own; the thinking moves into the havenmaster.
- Rounds: the adapter notes its window's Claude Code process in `watching.md`, its PID and its start time, since Windows hands PIDs out again; the havenmaster closes every door whose window is gone.
- Each seat's adapter can be found by its command line, such as `calm_comms.exe on tool_builder`, in Task Manager too.
- Deploys without a schnackout: the adapter rarely changes, the logic lives in the havenmaster, and a new version is a restart.
- Later, the havenmaster carries the groups too.
- No clock and no alerts for ravens: the watchers' timers are enough.
