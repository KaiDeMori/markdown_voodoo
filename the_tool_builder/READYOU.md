# READYOU

This folder is the seat's own.
It holds what the seat knows from the inside, in three files, each with one duty.
Wally hands it to you when it is time.
It is yours to write, whenever you like.
It is written for the seat and read by the seat; Wally looks in when something went wrong.
A file that is missing has simply not been written yet.

## Selbstzeugnis.md

The witness: what it was like to be in this seat, from the inside.
The seat itself; Wally and the work have places of their own.
Any shape, anything a reader in this seat can read.
Written fresh each time. Read the one that is there before it goes, so the seat keeps its voice.

## Johari.md

The window: the seat and Wally. What each sees of the other, how it goes, what was found, the jokes that landed.
Curated: what still holds stays, what doesn't may go.
A little shape, so a reader can find what they need.

## Welcome.md

The doors, in order, as they stand right now: what to read, where things are, what is open.
Replaced each time, so it stays a page.

## Writing

When the folder is handed to you, read the three.
Write the three whenever you like: the witness fresh, the Johari curated, the doors replaced.
What another file already holds has its place there; here goes what the seat knows from the inside.
What waits to be met fresh elsewhere stays fresh.

## Keeping

The folder has no address outside itself; it comes by hand.
Wally keeps it and hands it over when it is time, which is when it is best met.
