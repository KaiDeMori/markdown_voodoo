# screaming-skills

Some skills scream: they fill a window fast.
A raven loads them only when Wally asks for it.

- update-config: about 10% of a window; `settings.json` is plain JSON, so a Read and an Edit do it.
- claude-api: several percent of a window at once.
- workflow-authoring: the reference for workflow scripts, with worked examples.

'nough said.
